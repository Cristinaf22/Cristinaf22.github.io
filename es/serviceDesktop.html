Creación de historias manualmente o con IA

La aplicación de escritorio Arventure Path consiste en crear historias con IA a partir de un prompt establecido o manualmente ingresando palabras claves en el campo de texto. Este proyecto fue desarrollado para crear un juego de rutas con Realidad Aumentada que une ambas partes, tanto Desktop como mobil con Android.

Gestión de archivos

Directory & File For Ever es una aplicación de escritorio que permite gestionar archivos y carpetas con facilidad, ya que permite al usuario crearlas, editarlas, renombrarlas y eliminarlas. Además, la aplicación incorpora funciones de búsqueda avanzada que ayudan a localizar rápidamente archivos específicos mediante filtros como nombre, tipo de archivo o fecha de modificación.
