ANDROID

Multimedia Application

The multimedia application for Android takes advantage of the device’s built-in features, such as the microphone, camera, and media player. It allows users to capture photos, videos, and audio, view and play them at any time, and includes basic tools to edit and manage files in a practical and centralized way.

Augmented Reality Route Game

Arventure Path is a Route Game application for Android where the user selects a story, either pre-generated with the help of AI or created manually on the Desktop application. As the user follows the route in the real world, interactive Augmented Reality events appear, enriching the experience and turning each journey into a unique adventure.

Ping Pong Game with LibGDX Library

The Ping Pong game was developed for Android using the LibGDX library, which simplifies the management of graphics, physics, and event handling. Thanks to this tool, the game delivers smooth performance, real-time animations, and an interactive experience that allows users to enjoy dynamic and entertaining matches.

Cultural Event Management

This tablet application was developed for managing cultural events for a city council. The app allows users to view the event schedule, access detailed information for each activity, and organize attendance, providing a practical and accessible tool for promoting and managing the municipal cultural agenda.
